ComplyVision was built specifically according to the official Software Requirements Specification.

Mandatory Rule Set (Rule 6, Legal Metrology 2011)

  • Rule 6(1)(a): Name and complete address of the manufacturer or packer.
  • Rule 6(1)(b): Net quantity in standard metric units (g, kg, ml, l).
  • Rule 6(1)(d): Month and year of manufacture or pre-packing.
  • Rule 6(1)(e): Maximum Retail Price (MRP) inclusive of all taxes.
  • Rule 6(1)(f): Name, address, phone or email of the consumer care contact.

Standout Technical Differentiators

  • Font-Height Ratio Checker (FR-6): Evaluates whether the MRP declaration font size is compliant relative to surrounding packaging text.
  • Live JSON Rule Amendments (NFR-5, FR-11): Dynamically reloadable rules without recompilation or redeployment.
  • Degraded & Blurry Image Handling (NFR-3): Laplacian variance blur detection gracefully alerts users to re-capture instead of crashing.
  • Sub-5 Second Processing (NFR-1): End-to-end local inference runs in < 2 seconds.
